# HandJob

**We Know Exactly Where Your Fingers Should Go.**

HandJob was born out of my need to learn to play MIDI files without guessing which hand should play each note. The name is a wink: the best HandJob starts with knowing where your hands—and eventually your fingers—belong. Today it helps assign notes to the left or right hand; individual fingering is still planned.
